# 100 AI Apps

> 用 100 个真实 App，完成我的 AI 工程化训练。

这是一个长期实践项目。

目标不是为了凑够 100 个 Demo，而是通过持续设计、开发、发布和复盘真实应用，系统掌握 AI 时代的产品开发能力。

我会尽量让每一个 App 都解决一个具体问题，并完成从想法、需求、UI、开发、上线到复盘的完整闭环。

---

## 🎯 Challenge

**Build 100 Apps with AI.**

通过 100 个真实项目，持续训练这些能力：

- 发现真实需求
- 产品需求分析
- UI / UX 设计
- Prompt Engineering
- AI Coding
- Agent / Skill / MCP
- 前端与全栈开发
- 本地优先与轻后端架构
- Web / PWA / 小程序 / iOS / Android
- 部署与发布
- 数据分析与产品迭代
- AI 产品商业化

最终目标不是“会用 AI”，而是形成一套稳定的 **AI 产品开发方法论和工程体系**。

## 🧩 每个 App 的开发闭环

每个项目尽量经过下面的完整流程：

```text
Idea
  ↓
Problem
  ↓
Requirement
  ↓
UI / UX
  ↓
Technical Design
  ↓
AI Development
  ↓
Testing
  ↓
Release
  ↓
Feedback
  ↓
Iteration
  ↓
```

## 🧠 AI Learning Roadmap

100 个 App 不只是产品数量，也是一条 AI 学习路线。

### Stage 1 — AI Coding

先学会让 AI 高质量完成软件开发工作。

- Prompt
- Context
- Codex
- Claude Code
- AGENTS.md
- Debug
- Review
- Test

### Stage 2 — AI Workflow

把一次性的 AI 对话变成稳定工作流。

- Skill
- Tool
- Workflow
- MCP
- Structured Output
- Automation

### Stage 3 — AI Agent

让 AI 从“写代码工具”变成“执行任务的员工”。

- Agent
- Planning
- Tool Calling
- Memory
- Multi-Agent
- Runtime

### Stage 4 — AI Product

最终将 AI 能力沉淀成真正有人使用的产品。

- 产品设计
- AI Native UX
- 成本
- 数据
- 增长
- 商业化

## 📌 Principles

这个挑战遵循几个原则：

**1. 小而完整**

宁可做一个解决具体问题的小产品，也不做功能庞大的半成品。

**2. 真实可用**

尽可能做到自己、家人或真实用户可以使用，而不是只做 Demo。

**3. AI First**

尽可能让 AI 参与需求、设计、编码、测试、文档和发布的完整流程。

**4. 每个项目必须有收获**

完成 App 只是结果，更重要的是记录这次项目学到了什么。

**5. 持续发布**

不要追求一次做到完美，先完成，再迭代。
