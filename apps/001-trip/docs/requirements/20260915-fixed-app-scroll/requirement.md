# 需求方案：固定 App 外层并内部滚动

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

当前页面由浏览器文档整体滚动，`.app-shell` 和 `.page` 仅设置最小视口高度。在移动端下拉到页面边界时，文档可能产生橡皮筋回弹并露出 App 外层背景，不符合独立 PWA 的固定 App Shell 体验。

## 需求目标

固定 App 外层到可用视口，禁止整页下拉露底；长列表和表单在 App 内部正常滚动，路由切换时回到内部滚动顶部。

## 需求范围

### 范围内

- 固定 `html/body/#root` 和 `.app-shell` 的视口布局。
- 新增单一内部滚动容器承载路由页面。
- 控制外层和内部滚动边界的 overscroll 行为。
- 路由切换时重置内部滚动位置。
- 验证短页、长页、路由切换及现有弹层可用性。
- 版本升至 `0.1.4` 并同步 npm lock。

### 范围外

- 使用全局 `touchmove` 拦截。
- 修改页面业务、导航、表单、弹层或数字键盘交互。
- 承诺未经真实设备验证的所有 iOS/Safari 版本完全无系统级回弹。

## 业务规则

1. App Shell 固定，文档本身不滚动。
2. 页面内容统一在 App 内部容器滚动，长内容仍可访问。
3. 路由 pathname 变化后，新页面内部滚动位置重置为顶部。
4. Ant Design Mobile 弹层和键盘继续使用现有 portal/fixed 行为。

## 验收标准

1. `html/body/#root` 与 `.app-shell` 固定占满可用视口且不产生文档滚动。
2. 短页不能通过整页下拉露出 App 外背景，长页可在内部正常滚动。
3. 从已滚动页面切换路由后，内部滚动位置为 0。
4. 日期选择器、菜单或费用弹层保持可打开和关闭。
5. 不存在全局 `touchmove preventDefault`。
6. 版本为 `0.1.4`，测试、类型检查与生产构建通过。
