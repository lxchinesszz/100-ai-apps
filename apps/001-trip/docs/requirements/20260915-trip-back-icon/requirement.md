# 需求方案：创建旅行页使用返回箭头

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

创建旅行页左上角当前显示“取消”文字。用户希望改为更符合移动端返回语义的左箭头图标。

## 需求目标

将创建旅行页左上角“取消”替换为可访问、易点击的返回箭头，同时保持现有返回处理和未保存内容保护行为。

## 需求范围

### 范围内

- 创建旅行页左上角使用 Lucide 返回箭头。
- 复用现有 `.icon-button` 触摸区域与现有 `cancel` 点击处理。
- 为图标按钮增加明确 `aria-label`。
- 应用版本升至 `0.1.2` 并同步 npm lock；沿用已有构建标识机制。

### 范围外

- 修改编辑旅行页或其他页面导航。
- 修改未保存确认、保存、路由或全屏逻辑。
- 新增共享控件或依赖。

## 业务规则

1. 仅新建旅行状态显示返回箭头；编辑旅行状态继续保留原“取消”文字，避免扩大页面范围。
2. 返回箭头继续调用现有 `cancel`，忙碌时保持禁用。
3. 图标按钮触摸区域保持现有 `.icon-button` 的 `40 × 44px`。

## 验收标准

1. 创建旅行页左上角显示返回左箭头，不再显示“取消”文字。
2. 图标按钮具有“返回旅行列表”无障碍名称。
3. 点击仍执行现有 `cancel` 逻辑，未保存保护行为不变。
4. 编辑旅行页与其他页面不受影响。
5. 版本为 `0.1.2`，测试、类型检查与生产构建通过。

## 待确认事项

- 无；用户已明确要求将截图中创建旅行页的“取消”改为返回左箭头。
