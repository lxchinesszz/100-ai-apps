# 需求方案：首页使用设置齿轮图标

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

首页右上角进入设置与备份的入口当前使用三个点图标，用户希望改为语义更明确的设置齿轮图标。

## 需求目标

将首页设置入口替换为齿轮图标，同时保持原尺寸、可访问名称、点击区域和导航行为。

## 需求范围

### 范围内

- 首页右上角 `MoreHorizontal` 替换为 Lucide `Settings`。
- 保持图标 23px、按钮类名、`aria-label` 和 `/backup` 导航。
- 版本升至 `0.1.6` 并同步 npm lock。

### 范围外

- 修改备份页、其他图标、按钮布局或导航结构。
- 新增依赖或自动化测试。

## 业务规则

1. 设置入口继续显示在首页右上角。
2. 点击后继续进入 `/backup`。
3. 无障碍名称继续为“设置与备份”。

## 验收标准

1. 首页右上角显示设置齿轮，不再显示三个点。
2. 图标尺寸仍为 23px，点击区域与导航行为不变。
3. 版本为 `0.1.6`，测试、类型检查与生产构建通过。

## 待确认事项

- 无；用户已明确要求将三个点改为设置齿轮图标。
