# 需求方案：修复人数加减按钮形状

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

旅行表单的人数 Stepper 将组件容器宽度设为 100%，同时把容器圆角变量设为 50%。组件本身会裁切溢出内容，导致横向拉伸后的整体胶囊裁切影响两端按钮轮廓，按钮不再呈现稳定的 App 风格形状。

## 需求目标

让人数 Stepper 两端加减按钮保持规则、居中且易点击的圆形视觉，并提供清晰的按压和禁用状态。

## 需求范围

### 范围内

- 调整人数 Stepper 的局部 CSS。
- 保持 36px 圆形视觉与至少 44px 点击目标。
- 明确图标居中、按压反馈和禁用反馈。
- 应用版本升至 `0.1.3` 并同步 npm lock。

### 范围外

- 修改人数范围、默认值、状态或保存逻辑。
- 修改其他表单控件、其他页面或全屏配置。
- 替换 Stepper 组件或新增依赖。

## 业务规则

1. 人数继续限制为 1 至 99，步进与整数逻辑不变。
2. 按钮点击目标至少为 44 × 44px，视觉圆形直径为 36px。
3. 达到边界时保留可辨识的禁用状态，按压时提供轻量缩放反馈。

## 验收标准

1. 加减按钮均呈规则圆形，图标水平和垂直居中。
2. 点击区域至少 44 × 44px，按压与禁用状态清晰。
3. 人数范围仍为 1 至 99，原交互逻辑不变。
4. 版本为 `0.1.3`，测试、类型检查与生产构建通过。
5. 可用浏览器环境下完成创建旅行页视觉核对；不可用时记录限制。
