# 需求方案：修复移动端底部色带

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

固定 App Shell 后，用户截图中底部出现与页面白色不一致的色带。截图不能单独证明 `100dvh` 是唯一原因，但当前 fixed shell 同时使用 `inset: 0` 和显式 `height: 100dvh`，且根背景为灰色，存在视口边界计算或底色不一致时暴露灰底的风险。

## 需求目标

让移动端 App Shell 由四边定位自然填满可用视口，并统一外层与页面底色为白色，同时保留桌面端灰色画布和内部滚动。

## 需求范围

### 范围内

- 移除移动端 fixed App Shell 的显式 `100dvh` 高度。
- 移动端 `html/body/#root` 使用白色背景，桌面断点恢复灰色背景。
- 页面统一增加底部 safe-area padding，并消除表单重复 safe-area padding。
- 验证短页、长页、移动端底部边界和桌面画布。
- 版本升至 `0.1.5` 并同步 npm lock。

### 范围外

- 修改内部滚动架构、业务流程、弹层或全屏 meta。
- 将截图中的色带归因于未经真机复现确认的单一浏览器机制。

## 业务规则

1. 移动端 App Shell 使用 `position: fixed; inset: 0` 自然确定边界。
2. 移动端根背景与 App 页面保持白色，桌面端继续显示灰色外围画布。
3. 普通页面由 `.page` 统一避让底部安全区；已有 fixed 底部操作与弹层继续保留自身 safe-area。
4. 表单不重复叠加 safe-area，仅保留普通底部间距。

## 验收标准

1. 移动端 shell 无显式 `height: 100dvh`，上下边界由 inset 确定。
2. 移动端 viewport 底部为白色，不暴露灰色根背景。
3. 桌面端 App 外围背景仍为灰色。
4. 页面底部内容避开 safe area，表单无重复 safe-area padding。
5. 内部滚动和路由行为不回退。
6. 版本为 `0.1.5`，测试、类型检查与生产构建通过。
