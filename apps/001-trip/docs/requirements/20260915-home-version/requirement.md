# 需求方案：首页显示版本号

## 基本信息

- 需求编号：无
- 提出日期：2026-09-15
- 当前状态：Done
- 关联人员：用户、Codex

## 背景与问题

用户已确认 iPhone 主屏幕全屏显示正常，但当前首页没有可见版本标识，发布后无法直接区分应用版本及同版本的不同构建。

## 需求目标

在首页“旅记”品牌名称旁显示应用版本号和构建时间标识，便于用户验证当前部署版本。

## 需求范围

### 范围内

- 将应用版本从 `0.1.0` 升至 `0.1.1`，同步 npm 与 pnpm 锁文件。
- 构建时注入 package version 和固定构建时间标识。
- 在首页“旅记”旁展示版本与构建标识。
- 开发环境使用明确且稳定的 `DEV` 标识。

### 范围外

- 修改已确认正常的全屏与 PWA 配置。
- 增加版本详情页、更新日志或远程版本检查。
- 改变现有首页信息结构与业务流程。

## 业务规则

1. 版本号以 `package.json` 为唯一来源。
2. 生产构建时间使用上海时区，并在标识中明确 `CST`。
3. 单次构建内标识固定，不在客户端运行时动态变化。
4. 开发环境显示 `DEV`，避免误认为正式构建。

## 验收标准

1. 首页“旅记”旁显示 `v0.1.1` 和构建标识。
2. 生产构建标识包含上海时间与 `CST`，开发环境显示 `DEV`。
3. `package.json` 与可记录项目版本的 `package-lock.json` 一致为 `0.1.1`，`pnpm-lock.yaml` 与当前依赖声明一致。
4. 测试、类型检查与生产构建通过。
5. 不修改现有全屏配置。

## 待确认事项

- 无；用户已明确要求增加首页版本号并在确认全屏正常后继续部署准备。
