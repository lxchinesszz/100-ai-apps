# 旅记 · 开发与部署

## 本地运行

使用 Node.js 22.12+（本次验证为 Node.js 24.3.0）。

```sh
npm ci
npm run dev
```

开发地址通常为 http://localhost:5173/trip/。开发模式不注册生产 Service Worker。

```sh
npm test
npm run build
npm run preview
```

生产预览通常为 http://localhost:4173/trip/，用于检查真实构建及 PWA。若端口被占用，以终端显示的地址为准。账本按浏览器及 origin 隔离，5173、4173 和正式域名互不共享记录。

`npm run build` 自动进行类型检查，生成 dist。应用已配置按页面拆分及完整静态资源预缓存。首次联网加载并出现“已准备好，可以离线使用了”后再测试离线。

## 本次实现

- React 18 + TypeScript + Vite；Ant Design Mobile 基础组件，定制 iOS 风格。
- 旅行列表、创建/编辑、四种内置封面、人数与日期选择。
- 预算剩余、日建议、条件预测、分类筛选、按日流水与分页。
- 记账弹层、数字键盘、备注与补记时间、支出编辑/删除、旅行级联删除。
- Dexie / IndexedDB 持久化，整数分计算、防重复提交、事务写入。
- JSON 备份导出与严格校验恢复，恢复失败事务回滚。
- PWA 图标、manifest、离线预缓存、用户确认更新、未保存输入保护。
- 首次安装指引、存储保护申请、读取失败与缺失旅行状态。

内置封面为项目原创 SVG 风景插画，应用图标由本项目绘制；不是效果图中的城市摄影照片。素材源在 scripts/generate-assets.mjs，可使用 `node scripts/generate-assets.mjs` 重新生成。不会调用远程图片、在线字体或定位服务。

## 又拍云发布

1. 使用现有 ai-skills 空间及已绑定 HTTPS 域名 sks.springlearn.cn，部署子目录为 /trip/。
2. 本地执行测试和构建，保留上一发行版本的完整 dist 作为回退参考。
3. 将 dist **里面的文件**上传到空间的 /trip/，保证 `/trip/index.html` 可访问，而不是上传成 `/trip/dist/index.html`。
4. 先上传哈希资源，再更新 index.html、manifest，最后更新 sw.js 及其依赖；保留旧哈希资源，防止旧客户端加载失败。
5. 对入口 HTML、manifest、sw.js 使用协商缓存或短缓存；assets 内带哈希文件使用长期缓存。
6. 刷新入口与 Service Worker 的 CDN 缓存，并核对实际响应的 MIME、缓存头和 HTTPS。
7. 在 iPhone Safari 打开正式域名 → 分享 → 添加到主屏幕 → 从图标联网打开一次 → 飞行模式测试查看和记账。

不要把又拍云凭据放进前端环境变量或 dist。应用没有账本上传 API，不需要将用户数据存到静态空间。普通局域网 HTTP 地址只适合页面预览，不能替代 HTTPS 下的 iPhone PWA 验收。

更新或回滚不能清空 IndexedDB。发生数据库 schema 变化时，先核实旧代码兼容性，再决定是否回滚静态产物。
