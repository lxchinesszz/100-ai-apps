# 技术方案：Web/PWA 规则文件中文命名

## 现状分析

现有六份专项规则均为 `rules/web-pwa/` 下 Markdown 文件。当前有效引用位于该目录的 `README.md`、`KONSTA_UI.md`，以及上一项规则整理需求的变更记录。

## 方案设计

使用一一对应的中文文件名：`应用布局与运行.md`、`界面与交互.md`、`本地数据与离线.md`、`路由与发布.md`、`图标与静态资源.md`、`验收清单.md`。只重命名并替换当前引用，保留 `README.md`。

## 接口与数据影响

- API：无
- 数据库：无
- 配置：无
- 外部依赖：无

## 兼容性与风险

- 外部未纳入仓库的旧链接可能失效；仓库内所有当前有效引用需更新。历史文档如只是记录旧路径，按实际记录保留或说明重命名。

## 验证方案

1. 检查目录中文件名与数量。
2. 搜索旧文件名并检查所有 Markdown 相对链接。
3. 运行 `git diff --check`。
