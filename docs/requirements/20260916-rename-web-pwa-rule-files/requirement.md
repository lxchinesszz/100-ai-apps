## 背景与问题

`rules/web-pwa/` 当前除 `README.md` 外的六份规则文件使用英文文件名。用户要求它们使用中文命名。

## 需求目标

六份专项规则文件改为清晰的中文文件名，仓库内现行引用同步更新。

## 需求范围

### 范围内

- 重命名 `rules/web-pwa/` 六份专项规则文件。
- 更新 `README.md`、专项规则交叉引用和当前需求记录中的路径。

### 范围外

- 不改动规则内容、模板或 App 代码。

## 业务规则

1. `README.md` 保持原名。
2. 中文文件名与原有六份规则一一对应，链接目标必须存在。

## 验收标准

1. `rules/web-pwa/` 除 `README.md` 外的 `.md` 文件均使用中文文件名。
2. 仓库中当前有效的规则链接不指向旧文件名。
3. 文件内容除文件名引用外无业务规则变化。
