## 现状分析

模板 `NEW_APP.md`、`vite.config.ts`、`package.json` 和应用内 `scripts/youpai-sync.mjs` 已核验：slug 驱动 base、Manifest 和部署目录；`pnpm deploy` 使用应用内脚本。模板固定 Konsta iOS Theme 和基础安全区域，且包含线上 Roboto；模板未安装 Font Awesome。现有平台规则对此有重复或冲突。
