# 需求方案：Web/PWA 规则与 create-pwa-app 模板对齐

## 基本信息

- 需求编号：无
- 提出日期：2026-09-16
- 当前状态：已完成
- 关联人员：用户、Codex

## 背景与问题

`create-pwa-app` 已生成 App 框架、PWA 配置、安全区域基础实现、应用内部署脚本和图标生成能力。现有 `rules/web-pwa/` 重复规定框架实现，仍要求仓库根脚本、Font Awesome 和系统字体，与模板不一致。

## 需求目标

规则只约束在模板上继续开发业务功能及验收；框架实现以模板为准。部署采用应用内脚本及 `app.config.ts` 的 slug；移除当前字体规则，遵循模板。

## 需求范围

### 范围内

- 精简 `rules/web-pwa/` 七份文档，删除重复的框架实现说明。
- 保留业务 UI、数据、路由、资源与验收边界。
- 更新部署和字体、图标规则，使之与模板一致。

### 范围外

- 不修改 `web-pwa-starter` 模板或现有 App 代码。
- 不发布应用。

## 业务规则

1. `app.config.ts` 是元数据和部署目录的来源；发布使用模板应用内命令。
2. 字体沿用模板配置，不设置仓库级字体强制方案。
3. 模板负责基础 App Shell 与安全区域；新业务界面仍须避免遮挡与重复占位。

## 验收标准

1. 七份规则不再要求手写模板已生成的框架配置。
2. 不再出现强制 Font Awesome、系统字体、仓库根部署脚本或 `npm run build` 作为新模板默认命令。
3. 保留新增业务界面的 UI、数据和验收规则，交叉引用有效。

## 待确认事项

- 无。用户已确认部署和字体两项处理方式。
