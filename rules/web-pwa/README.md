# Web / PWA 业务开发规范

本目录适用于 `100-ai-apps` 中使用 `create-pwa-app` 创建的 Web/PWA 应用。新应用的框架初始化、应用元数据、PWA 配置、安全区域基础实现、图标生成、构建与部署命令，以 `web-pwa-starter` 的 `NEW_APP.md` 和生成后的应用代码为准。本目录约束在此基础上开发业务功能及验收。

## 开发基线

- 开发前读取仓库 `AGENTS.md`、`rules/common/README.md`、本目录相关规则，以及应用内 `AGENTS.md`、`NEW_APP.md` 和 `app.config.ts`。
- 应用名称、描述、slug、主题颜色和页脚说明只在 `app.config.ts` 维护。不要在页面、Vite 配置或部署命令中再次写死。
- 默认优先静态应用与本地数据。业务明确需要远程能力时，在当前需求和技术方案中说明。
- 保留模板提供的 PWA 安装、离线缓存、版本显示和手动更新能力。新增功能不得破坏模板的 App Shell、安全区域或子目录部署。
- 使用应用自身的 `pnpm` 脚本验证。只有明确要求发布时才运行 `pnpm deploy`。
