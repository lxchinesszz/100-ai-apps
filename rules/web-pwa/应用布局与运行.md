# 页面布局与 iPhone 运行验收

`create-pwa-app` 已提供 PWA App Shell、动态视口和安全区域基础实现。新增页面应沿用生成应用的布局与 Konsta 配置，不重新实现根节点 viewport、安全区域或滚动锁定。

## 新增页面与固定区域

- Header、Tabbar、底部操作区与业务滚动内容须明确各自的布局位置；长内容应在预定内容区滚动，不使整个 document 意外滚动。
- 底部安全区域只计算一次。新增 Tabbar、Toolbar 或固定按钮时，先检查 Konsta 组件和现有容器是否已经占位，不在多层同时叠加底部 padding。
- 正常布局流中的底部组件已占高度时，内容区不再预留同一高度；脱离布局流的组件才按实际遮挡范围补偿。
- 新页面背景延伸到屏幕边缘，可操作内容避开 Dynamic Island 和 Home Indicator。
- 内容较长、横竖屏切换或 Safari 浏览器栏变化时，固定区域和滚动区域应保持可用。

## 触摸与输入

- 核心点击区域至少 `44 × 44px`，核心功能不依赖 hover。
- 文本输入字号至少 `16px`，避免 iPhone 聚焦时自动放大。
- 键盘弹出后，焦点输入框、关联提示和提交操作仍可见、可达；Sheet / Popup 内表单也应可滚动和提交。
- 不通过解除根节点滚动锁定来回避键盘问题。

## 验收

只对本次新增或受影响的界面检查：短内容无意外滚动，长内容可滚动，底部无重复空白或遮挡；输入时焦点和操作可达；常见 iPhone 宽度下布局可用。模板基础安全区域实现不要求每个 App 重复编写。
