# 图标与静态资源规范

## 应用图标

新应用按生成应用的 `NEW_APP.md` 替换 `public/favicon.svg`，运行 `pnpm generate:pwa-assets` 生成安装图标。修改图标后重新构建并检查 iPhone 主屏幕图标。

## 业务图标

- 选择图标时先检查应用现有组件和资源；同一业务语义在同一 App 内保持一致。
- 不用 Emoji 或 Unicode 字符模拟正式功能图标。
- 如果业务确需引入图标依赖，应按需导入并控制额外包体积；本规则不强制指定 Font Awesome 或其他图标库。
- 图标帮助识别操作，不以大量装饰图标替代文字或信息层级。

## 字体与资源

字体沿用 `create-pwa-app` 生成应用的配置，本目录不另设字体方案。新增字体、图片和关键资源时，检查离线表现和子目录资源路径。应用核心操作不应因为第三方资源不可用而失效。

静态资源放在应用既有的 `public/` 或由 Vite 构建处理；最终 URL 应位于当前 App 子目录，或由 Vite base 正确转换。
